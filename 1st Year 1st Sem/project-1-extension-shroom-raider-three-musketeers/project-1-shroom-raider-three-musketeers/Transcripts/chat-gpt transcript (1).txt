✅ PEP 8 CHECKLIST (Python Style Guide)
1️⃣ Code Layout & Formatting
☐ Use 4 spaces for indentation (no tabs)
☐ Lines are ≤ 79 characters (≤ 72 for comments/docstrings)
☐ One statement per line
☐ Blank lines:

2 blank lines between top-level functions/classes

1 blank line between methods inside a class

2️⃣ Imports
☐ Imports at the top of the file
☐ One import per line
☐ Order:

Standard library

Third-party libraries

Local modules

Example:

import os
import sys

import numpy as np

from mymodule import helper
☐ Avoid wildcard imports (from x import *)

3️⃣ Naming Conventions
☐ snake_case → variables & functions
☐ PascalCase → classes
☐ UPPER_CASE → constants
☐ _single_leading_underscore → internal use
☐ Avoid single-letter names except for loop counters (i, j)

4️⃣ Whitespace Rules
☐ No extra spaces inside:

(a, b)     # ✔
(a , b )   # ✘
☐ Spaces around operators:

x = y + 1  # ✔
x=y+1      # ✘
☐ No trailing whitespace at end of lines

5️⃣ Comments
☐ Comments are complete sentences
☐ Start with a capital letter
☐ Space after #

# This calculates the total score
☐ Avoid obvious comments:

x += 1  # increment x ❌
6️⃣ Docstrings
☐ Use triple quotes """ """
☐ Describe what, not how
☐ Required for:

Modules

Classes

Public functions

Example:

def add(a, b):
    """Return the sum of two numbers."""
    return a + b
7️⃣ Expressions & Statements
☐ Prefer readability over clever code
☐ Avoid deeply nested code
☐ Use parentheses instead of line-continuation backslashes
☐ Use is for None

if x is None:
8️⃣ Boolean Checks
☐ Don’t compare to True or False

if flag:        # ✔
if flag == True # ✘
☐ Use truthiness:

if items:
9️⃣ Exception Handling
☐ Catch specific exceptions

except ValueError:
☐ Avoid bare except:

🔟 General Pythonic Style
☐ Use list comprehensions when readable
☐ Use enumerate() instead of manual counters
☐ Use with for file handling

🧠 PEP 8 Golden Rule
Code is read more often than it is written

If it’s clearer—even if longer—it’s better.

Yes ✅ — you can clear the terminal from inside a Python function, and this is a very common pattern.

✅ Recommended (cross-platform) way
import os


def clear_terminal():
    os.system("cls" if os.name == "nt" else "clear")
Call it anytime:

clear_terminal()
Why this works
cls → Windows

clear → Linux / macOS

os.name detects the OS automatically

🧪 Minimal version (inline)
os.system("cls" if os.name == "nt" else "clear")
⚠️ Important limitations (exam-worthy)
Works in real terminals (Command Prompt, PowerShell, Git Bash, Terminal)

❌ May NOT work in:

some IDE consoles

Jupyter notebooks

🧼 Jupyter / IPython alternative
from IPython.display import clear_output

def clear_terminal():
    clear_output(wait=True)
🧠 Why Python has no built-in clear()?
Because clearing the terminal is OS-specific, not a Python-language feature.

🧩 Best practice version (clean & PEP 8)
import os


def clear_terminal() -> None:
    """Clear the terminal screen."""
    command = "cls" if os.name == "nt" else "clear"
    os.system(command)
